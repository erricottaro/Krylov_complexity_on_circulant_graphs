# Krylov Spread Complexity of Chiral Discrete Systems

Python code for the computation of $\bar{\mathcal{C}}$ for finite-dimensional systems with arbitrary Hamiltonian $\hat{H}$. Given an initial state $\ket{\psi_0}$ undergoing a unitary evolution generated by $\hat{H}$, $\bar{\mathcal{C}}$ is defined as

$$
\bar{\mathcal{C}} = \sum_{n=0}^{K-1} n \sum_{j=0}^{K-1} |\braket{K_n|E_j}|^2|\braket{E_j|K_0}|^2.
$$

$\ket{E_j}$ being the j-th energy level, and $|K_n\rangle$ being the n-th Krylov vector, defined by the Lanczos algorithm 
```math
\begin{aligned}
\lvert A_{n+1}\rangle
&:= (\hat{H}-a_n)\lvert K_n\rangle
-b_n\lvert K_{n-1}\rangle, \\
\lvert K_{n+1}\rangle
&:= (b_{n+1})^{-1}\lvert A_{n+1}\rangle.
\end{aligned}
```

The Lanczos coefficients are defined as $a_n := \bra{K_n}\hat{H}\ket{K_n}$, $b_n^2 := \braket{A_n|A_n}$, with $b_0=0$ and $\ket{K_0}:=\ket{\psi_0}$. The algorithm stops at $n=K$, when $b_n=0$ and $K$ is the dimension of the Krylov subspace. In the basis $\{\ket{K_n}\}$ the Hamiltonian is tridiagonal, with $a_n$ on the diagonal and $b_n$ the off-diagonals elements.

The code performs Krylov reduction by turning the original Hamiltonian in Hessenberg form and then reshaping it in order to include only the first non zero $b_n$'s. In order to discriminate between null and positive $b_n$'s, they are compared with a parameter $\epsilon$ set at run-time.

Once $\hat{H}$ is expressed in Krylov basis, it is diagonalized. The overlaps $\braket{K_n|E_j}$ and $\braket{E_j|K_0}$ can be read from the elements of the eigenvectors matrix, as they are already expressed in the Krylov basis.
## Features

The routines in `krylov.py` perform Krylov reduction procedure and compute $\bar{\mathcal{C}}$ given arbitrary initial state and Hamiltonian.

*   `lanczos` receives a $n\times n$-shaped complex `nparray` as $\hat{H}$ and a $n$-shaped one as $\ket{\psi_0}$, together with the discrimination parameter $\epsilon$. It runs consistency check, raising exceptions whenever the shapes of the arrays are incompatible, or $\hat{H}$ is not Hermitian. Since `scipy.linalg.hessenberg` assumes the initial state in the form $(1,0,0...)^T$, a unitary change of basis is performed so that this is the case. It returns the Hamiltonian in Krylov form `H_kryl`.

* `compl_inf_time`receives a $k\times k$ `nparray` as $\hat{H}$ expressed in Krylov basis. It checks that $\hat{H}$ is real and tridiagonal, then diagonalizes it and extracts the overlaps to compute $\bar{\mathcal{C}}$. It returns it in the real variable `complexity`.
* `get_complexity` receives the same input parameters as `lanczos`. It calls both `lanczos` and `compl_inf_time`, wrapping them with `try` statements. It returns both `H_kryl` and `complexity`.

`ham_generator.py` and `states_gen.py` contain routines for the construction of some specific Hamiltonians and initial states.


* `adjacency_matrix`: given a `NetworkX` graph `g`, returns its adjacency matrix, casted to a `nparray`.
* `circulant_cycle`: returns a circulant complex adjacency matrix of a cycle graph of length `dim` with edge phase `phi`.
* `circulant_ham`: returns an arbitrary `dim` $\times$ `dim` circulant Hamiltonian specified by the weights coefficients `c`. For consistency, it must hold `len(c)`$=$`int(dim/2)+1` and `c[0]` real. If `dim` is even, then `c[-1]` must be real as well. 

* `router`: returns the Hamiltonian of the minimal quantum router, as defined in [1].

## Requirements

Python >=3.10 is required, with packages:

* `NumPy`

* `Scipy.linalg`
* `NetworkX`
